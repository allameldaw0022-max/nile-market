# 17. Design System

> احترافي · فخم · نظيف · بسيط · سريع · عربي RTL حقيقي · Mobile-first.
> نستلهم **سهولة الاستخدام** من منصات SaaS الحديثة، ولا ننسخ تصميم أو
> أصول أي منصة (بما فيها سلة).

## 17.1 الألوان — المعتمدة من المواصفات

```css
:root {
  --nile-blue:  #0B5ED7;   /* أساسي — أزرار، روابط، تركيز */
  --deep-navy:  #0B1F3A;   /* نصوص، ترويسات داكنة */
  --white:      #FFFFFF;
  --light-gray: #F5F7FA;   /* خلفية الصفحة */
  --gold:       #D9A441;   /* Accent فقط — ليس لونًا مسيطرًا */
}
```

> ⚠️ **تغيير إلزامي:** الكود الحالي يستخدم `#1e4fa3` و`#d4af37` وهي
> **لا تطابق** المواصفات. تُستبدل بالقيم أعلاه في المرحلة 1.

### المقاييس المشتقة
```css
--primary-50:#EBF2FE; --primary-100:#D6E4FD; --primary-500:#0B5ED7;
--primary-600:#094DB0; --primary-700:#073A85;
--navy-900:#0B1F3A; --navy-700:#16324F; --navy-500:#2C4A6B;
--gray-50:#F5F7FA; --gray-100:#EDF0F5; --gray-200:#DDE3EC;
--gray-400:#9AA5B5; --gray-600:#5A6675; --gray-800:#2A333F;
--success:#0F9D58; --warning:#E8A33D; --danger:#D64545; --info:#0B5ED7;
```

### قواعد الاستخدام
- الذهبي: شارات «مميز»، حالة VIP، تمييز باقة واحدة — **لا خلفيات واسعة ولا أزرار أساسية**.
- التباين: نص أساسي ≥ 4.5:1، نص كبير ≥ 3:1 (WCAG AA) — مفروض باختبار آلي.
- الحالة لا تُنقل باللون وحده: أيقونة + نص دائمًا (عمى الألوان).
- **تخصيص التاجر مقيّد:** لون ثانوي واحد من قائمة معتمدة مسبقًا + شعار +
  بانر. لا حرية تكسر Design System أو التباين (§9).

## 17.2 Typography
**Cairo** (عربي + لاتيني) — موجود ويُبقى.

| الدور | الحجم/الوزن | الاستخدام |
|---|---|---|
| Display | 32/40 · 800 | Hero |
| H1 | 24/32 · 700 | عنوان صفحة |
| H2 | 20/28 · 700 | قسم |
| H3 | 18/26 · 600 | بطاقة |
| Body | 15/24 · 400 | نص أساسي |
| Body-sm | 13/20 · 400 | ثانوي |
| Caption | 12/16 · 500 | تسميات |
| Numeric | `font-variant-numeric: tabular-nums` | **كل الأرقام والمبالغ** |

- `font-display: swap` + `preload` للوزنين 400/700 فقط ⇒ لا FOIT على
  الإنترنت الضعيف.
- الأرقام: عربية غربية (1234) — الأشيع في السودان للتعاملات.
- المبالغ: `١٥٬٠٠٠ ج.س` بفاصل آلاف وعرض ثابت.

## 17.3 المسافات والحواف
مقياس 4px: `1=4 · 2=8 · 3=12 · 4=16 · 6=24 · 8=32 · 12=48 · 16=64`
حواف: `sm=6 · md=10 · lg=14 · xl=20 · full=9999`
ظلال خفيفة فقط: `sm 0 1px 2px rgba(11,31,58,.06)` ·
`md 0 4px 12px rgba(11,31,58,.08)` · `lg 0 12px 32px rgba(11,31,58,.12)`

## 17.4 RTL حقيقي
- `dir="rtl"` على `<html>` ✅ موجود.
- **خصائص منطقية حصرًا**: `margin-inline-start` لا `margin-left`؛
  `padding-inline` · `inset-inline` · `border-inline`.
- الأيقونات الاتجاهية تُعكس (`rotate-180` للأسهم)؛ الأيقونات غير
  الاتجاهية (سلة، مستخدم) **لا تُعكس**.
- الرسوم البيانية: المحور الزمني من اليمين لليسار.
- حقول الهاتف/البريد/الرابط: `dir="ltr"` مع محاذاة يمين.
- المسافة البادئة للقوائم والاقتباسات منطقية.
- اختبار بصري على كل صفحة — RTL ليس عكسًا شكليًا.

## 17.6 التنقل على الهاتف
- **Storefront:** ترويسة ثابتة (شعار · بحث · سلة) + Bottom Nav
  (الرئيسية · التصنيفات · البحث · السلة · الحساب) + زر واتساب عائم.
- **Dashboard:** ترويسة (قائمة · بحث · جرس) + Bottom Nav (الرئيسية ·
  الطلبات · المنتجات · المزيد) + Drawer لبقية الأقسام.
- **Admin:** تبويبات أفقية قابلة للتمرير (موجود) + Drawer.
- أهداف اللمس ≥ 44×44px · بلا hover-only · إيماءات مع بديل بالنقر.

## 17.7 الحالات الموحّدة (إلزامية لكل صفحة)
`Loading (skeleton لا spinner صفحة كاملة)` · `Empty (+إجراء)` ·
`Error (+سبب +إعادة)` · `Forbidden (بلا كشف)` · `Offline` ·
`LimitReached (بطاقة ترقية)` · `Success (تأكيد صريح)`.

## 17.8 Accessibility
`label` مرتبط بكل حقل · `focus-visible` واضح بلون Nile Blue ·
تنقل كامل بلوحة المفاتيح · ARIA عند الحاجة (`aria-live` للـtoasts،
`role="dialog"` + focus trap) · `alt` لكل صورة ذات معنى · تباين AA ·
احترام `prefers-reduced-motion` · لغة الصفحة `ar` والاتجاه `rtl`.

## 17.9 التنفيذ
- Tailwind v4 بـ`@theme` (النمط الحالي) — التوكنز مصدر واحد.
- `src/components/ui/` = النظام الأساسي، لا مكوّن يُخترع داخل صفحة.
- **ممنوع** ألوان أو مسافات خام (`text-[#123456]`, `mt-[13px]`) — يُفحص
  بقاعدة ESLint/Stylelint في CI.
- كل مكوّن: نوع props صريح + حالات موثّقة + دعم RTL.
