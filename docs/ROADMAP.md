## P0 · الأساس والحوكمة
`npm install` · **قراءة `node_modules/next/dist/docs/`** · تحديث
Design Tokens إلى ألوان المواصفات · هيكل المجلدات · `proxy.ts` بحل
المستأجر · `server-only` على الطبقات الحساسة · Vitest + Playwright +
pgTAP + CI + gitleaks · قوالب الأخطاء والحالات · إصلاح hostname في
`next.config.ts`.
**الخروج:** CI أخضر · مسار وهمي محمي يعمل · Design System الأساسي مبني.

## P1 · الهوية والمصادقة
تسجيل/دخول/خروج · Google OAuth · تأكيد البريد · استعادة وإعادة تعيين ·
`getCurrentActor()` **فاشل مغلقًا** · مركز الأمان (جلسات · أجهزة · خروج
من الكل) · Rate Limiting · **2FA إلزامي لـAdmin** (D28).
**الخروج:** كل اختبارات المصادقة تمر · لا تعداد حسابات · لا ترقية دور
عبر بيانات التسجيل.

## P2 · قاعدة البيانات وRLS ★ (الأهم)
كل الجداول من [`DATABASE.md`](./DATABASE.md) · سكيمة `app` ودوالها ·
سياسات RLS كاملة لكل أمر · الجداول الإلحاقية محمية · `store_members`
والأدوار · `admin_members` والصلاحيات · `audit_logs` بـtriggers ·
**مجموعة pgTAP كاملة للعزل**.
**الخروج:** ✅ **كل اختبارات عزل المتاجر تمر** · صفر تحذيرات حرجة في
`get_advisors` · لا سياسة `for all` · لا سياسة ارتدادية.

## P3 · المتجر ولوحة التاجر (الأساس)
Onboarding Wizard مع Autosave · `stores` + `store_settings` ·
`store_members` (دعوة/أدوار/إيقاف) · هيكل اللوحة والتنقل ·
`store_invitations` (بديل `find_profile_id_by_email`).
**الخروج:** إنشاء متجر كامل · كل دور يرى ما يخصه فقط · لا فقدان بيانات
في الـWizard.

## P4 · الكتالوج والمخزون
التصنيفات · المنتجات · المتغيرات · الصور (رفع موقَّع + معالجة) ·
المخزون عبر الحركات حصرًا · تنبيه النفاد · SKU · استيراد/تصدير CSV
(Upload→Validate→Preview→Import) · البحث العربي.
**الخروج:** `inventory.quantity` غير قابل للتعديل المباشر · الاستيراد
يعرض الصفوف غير الصالحة · الحدود مفروضة في القاعدة.

## P5 · Storefront
حل المستأجر بالـHost · الرئيسية · المنتجات · التصنيفات · البحث والفلترة
· صفحة المنتج · Wishlist · السلة (زائر ومسجّل + دمج بلا تكرار) ·
واتساب · المشاركة · SEO كامل · حالات المتجر · Preview Mode.
**الخروج:** المتجر يبدو **موقعًا مستقلًا** · Lighthouse ≥ 90 · لا تسريب
بين مستأجرين · RTL سليم على الهاتف.

## P6 · الطلبات
مناطق التوصيل والأسعار · Checkout (زائر ومسجّل) · `create_order`
بالحساب الخادمي الكامل · `order_number` · Idempotency · آلة الحالة
بالـRPC + Triggers · `order_status_history` · حجز/خصم/إرجاع المخزون ·
صفحة النجاح والمتابعة · الفواتير · الكوبونات.
**الخروج:** ✅ رسوم التوصيل والأسعار والخصم **كلها من الخادم** ·
الضغط المزدوج ⇒ طلب واحد · كل انتقال ممنوع مرفوض · المخزون دقيق.

## P7 · الدفع والنظام المالي
`payments` + آلة حالتها · COD · التحويل البنكي مع إثبات · Bankak (حسب
Q6) · `ledger_entries` إلحاقي محمي · الاستردادات + الموافقات ·
تقارير مالية أساسية.
**الخروج:** لا تعديل/حذف لأي سجل مالي بأي دور · Idempotency فعّال ·
الاسترداد يولّد عكسًا ولا يمسّ الأصل.

## P8 · الاشتراكات والـEntitlements
`plans` + `plan_entitlements` · `subscriptions` + آلة الحالة ·
`assert_within_limit` في القاعدة · طلبات الاشتراك والاعتماد ·
Upgrade/Downgrade · pg_cron للكنس · بطاقات الترقية · الفواتير.
**الخروج:** الحد مفروض في **الطبقات الثلاث** · لا حذف بيانات عند
الانتهاء أو التخفيض · رسائل واضحة بدل فشل غامض.

## P9 · الشركاء والعمولات
`partners` + الدعوة · رابط الإحالة والكوكي الخادمي · قاعدة الإسناد Last-touch/30 يومًا (D19)
· `referrals` · `post_commission_for_payment` · `reverse_commission` ·
`partner_payouts` · لوحة الشريك · إدارة الشركاء من Admin.
**الخروج:** ✅ 20,000−5,000 ⇒ **7,500** · لا عمولة مكررة · لا صرف مزدوج
· العكس بقيد جديد · الشريك لا يرى بيانات التاجر التجارية.

## P10 · الدومينات
`store_domains` · النطاق الفرعي لكل متجر · إضافة دومين مخصص · تعليمات
DNS · Job التحقق · تكامل `HostingProvider` المعزول (D21) · SSL · الأساسي وwww ·
الإيقاف والإزالة وإعادة الربط · SEO على الدومين الأساسي · إدارة من Admin.
**الخروج:** لا دومين لمتجرين · إعادة الربط تتطلب تحققًا جديدًا ·
canonical صحيح.

## P11 · الإشعارات والمهام الخلفية
`notifications` + المركز · `email_outbox` + `EmailProvider` + **Resend** (D24) ·
القوالب العربية · `job_queue` + المعالج · pg_cron · Deduplication ·
إعادة المحاولة الأسّية.
**الخروج:** لا إشعار مكرر · فشل البريد لا يُسقط شيئًا · لا إرسال داخل
دورة الطلب.

## P12 · الدعم
التذاكر والرسائل · **الملاحظات الداخلية في جدول منفصل** · المرفقات ·
آلة الحالة · التعيين والتصعيد · لوحة الدعم · الإحصائيات · العزل الكامل.
**الخروج:** ✅ صاحب التذكرة لا يقرأ الملاحظات الداخلية بأي طريق ·
عزل التذاكر بين المتاجر · موظف الدعم لا يرى المالية.

## P13 · لوحة Admin
كل الأقسام في [`ROUTES.md §11.5`](./ROUTES.md) · موظفو Admin والصلاحيات
حسب الأقسام · **Data Access Matrix** · Feature Flags (منع خادمي) ·
System Health · Maintenance · التقارير · سجل التدقيق.
**الخروج:** موظف بصلاحية قسم واحد لا يصل لغيره لا بالواجهة ولا بالـAPI ·
لا حذف لسجل التدقيق لأي أحد.

## P14 · الأمان والأداء والـPWA
مراجعة كاملة لقائمة [`SECURITY.md`](./SECURITY.md) · CSP · Rate Limiting
شامل · مراجعة كل السياسات · الفهارس وقتل N+1 · `analytics_daily` ·
PWA وOffline وAutosave · Lighthouse CI.
**الخروج:** كل بنود §16.14 محققة · الأهداف في §18.1 محققة.

## P15 · الاختبار الشامل والإطلاق
تشغيل كل المجموعات · اختبار يدوي على جهاز حقيقي بشبكة ضعيفة ·
اختبار استعادة نسخة احتياطية · قائمة الإطلاق في

**الخروج:** Definition of Done أدناه — كل بند ✅.

## 21.2 Definition of Done — متى يكون Nile Market جاهزًا؟

> ليس «الواجهة جميلة» ولا «الصفحات موجودة» ولا «الأزرار تعمل شكليًا».

### النظام مترابط فعليًا
- [ ] تاجر يسجّل → ينشئ متجرًا → يضيف منتجًا → ينشر → يستقبل طلبًا →
      يديره → يُسجَّل الدفع → يصدر فاتورة — **بلا خطوة يدوية في القاعدة**
- [ ] زبون يشتري كزائر وكمسجّل، ويتابع طلبه
- [ ] اشتراك يُدفع → يُعتمد → الميزات سارية → **عمولة الشريك مسجَّلة تلقائيًا**
- [ ] شريك يرى مستحقاته ويطلب صرفًا ويُسجَّل الصرف
- [ ] تذكرة دعم تُفتح وتُعالَج وتُغلق مع إشعارات

### قاعدة البيانات والأمان
- [ ] RLS مفعّل على كل جدول بسياسات صريحة لكل أمر
- [ ] ✅ **كل اختبارات عزل المتاجر تمر** — متجر A لا يصل إلى B بأي طريق
- [ ] الصلاحيات مفروضة على الخادم والقاعدة، وكل دور مختبَر
- [ ] الجداول المالية والتدقيقية إلحاقية ومحمية
- [ ] صفر تحذيرات حرجة في `get_advisors`
- [ ] لا أسرار في المستودع ولا في المتصفح

### المال
- [ ] كل المبالغ تُحسب خادميًا — **صفر ثقة بالمتصفح**
- [ ] Idempotency على: الطلبات · الدفعات · العمولات · الصرف · الاستردادات
- [ ] لا عمولة مكررة ولا صرف مزدوج (**اختبار متزامن ناجح**)
- [ ] الاسترداد يولّد عكسًا ولا يحذف الأصل
- [ ] لا سجل مالي يُعدَّل أو يُحذف بأي دور

### الاشتراكات
- [ ] الحدود مفروضة في الواجهة والخادم والقاعدة
- [ ] انتهاء الاشتراك **لا يحذف** متجرًا ولا منتجات ولا طلبات ولا سجلات مالية
- [ ] Downgrade لا يحذف شيئًا — يمنع الجديد فقط
- [ ] كل تجاوز حد يعرض رسالة وخيار ترقية، لا فشلًا غامضًا

### التجربة
- [ ] عربي RTL حقيقي في كل شاشة
- [ ] Mobile-first مختبَر على 390px/768px/1280px
- [ ] Loading · Empty · Error · Offline · Forbidden · LimitReached في **كل** صفحة
- [ ] Lighthouse ≥ 90 لصفحات المتجر
- [ ] PWA قابلة للتثبيت مع سلوك offline وAutosave
- [ ] لا فقدان بيانات نماذج عند انقطاع الاتصال

### التشغيل
- [ ] Migrations مطبَّقة ومراجَعة
- [ ] نسخ احتياطي يعمل و**استعادة مختبَرة**
- [ ] Monitoring وSystem Health فعّالان
- [ ] Maintenance Mode يعمل بلا إسقاط المتاجر
- [ ] الصفحات القانونية منشورة
- [ ] **لا بيانات Mock ولا أزرار معطّلة ولا صفحات وهمية في الإنتاج**

### التوثيق
- [ ] `/docs` محدَّث ومطابق للمُنفَّذ فعليًا
- [ ] كل قرار في `OPEN-QUESTIONS.md` محسوم وموثَّق في `NILE-MARKET-SPEC.md`
